# phenotyping/output (not in git; Pantry layout)

Per dataset (`vestibular/`, `utricle/`, `saccule/`): normalised phenotype tables `<modality>.bed.gz` (+ `.tbi`) and
`<modality>.phenotype_groups.txt` for the 7 modalities (expression, isoforms, splicing, alt_TSS, alt_polyA, stability,
RNA_editing; RNA editing with missing values for sites below the coverage cutoff) and cross_modality; `unnorm/`:
unnormalised values (TPM, ratios, editing levels).
